A single original one-liner, written by a small Python program, for the
[One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a)
competition on [make.fun](https://make.fun).

Run it with:

```sh
python3 main.py
```

It writes exactly one funny line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when the variable is unset).
